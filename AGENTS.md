# Contribution instructions

- Write public project content in English.
- Keep the repository limited to reusable methods and original examples.
- Do not add private game files, third-party books, or generated source documents.
- Preserve the distinction between rules, inferences, uncertainties, problems, and proposals.
- Add capabilities only after an end-to-end example demonstrates the need.
- Run `python -m unittest discover -s tests` after changing the skill or examples.
